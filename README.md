# Focus Glass / فوکوس

A calm, glass‑style Pomodoro timer for Android — Material 3 with an iOS‑inspired glass theme, daily goal & streak card, detailed stats, and full Persian (فارسی) translation.

یک تایمر پومودوروی شیشه‌ای و آرام برای اندروید، با کارت «امروز» (هدف روزانه و استریک)، آمار دقیق و ترجمه‌ی کامل فارسی.
